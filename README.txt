FULLY EDITABLE V7
1. Extract the ZIP first.
2. Open index.html from the extracted folder.
3. Click Edit Page.
4. Text with red dotted outlines can be clicked and typed over.
5. Photos/thumbnails: click them while Edit Page is active and choose a new image.
6. Portfolio Watch/Open buttons: in Edit mode click the button to paste a URL or type FILE for PDF/PPT.
7. Click Save when finished.

This build uses a fresh editor/storage version so older saved browser data cannot replace the new pages.


V10 FIX: Portfolio sections 3, 4 and 6 are forced to the updated built-in version even if an older portfolio page was previously saved in the browser editor. Other saved page edits remain unchanged.
